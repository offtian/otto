# Disk encryption — check it is on

1. Firm laptops must have full-disk encryption enabled — FileVault on Mac, BitLocker on Windows. This is usually turned on at setup, but verify if prompted by a compliance alert.
2. On Mac: System Settings → Privacy & Security → FileVault. It should read "FileVault is on". If not, click "Turn On" and let it finish encrypting (you can keep working).
3. On Windows: open Settings → Privacy & security → Device encryption, or search "Manage BitLocker". Each drive should read "On".
4. If turning it on asks where to store the recovery key, choose "Save to your firm account" — never store it only on the same device or a personal account.
5. Encryption is stuck at 0% or the option is greyed out: this usually means the disk or TPM needs attention — do not force it.
6. Compliance still flags the device after encryption shows "On": escalate with a screenshot of the encryption status and the alert text.
