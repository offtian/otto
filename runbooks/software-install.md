# Software — install an approved application

1. Open the Self Service portal and search the catalogue for the app. Approved software installs from here without admin rights.
2. If the app is listed, click "Install" and wait — it deploys in the background; a restart is only needed if the app says so.
3. If the app is *not* in the catalogue, it needs a software request: use "Request software", pick the app, and give a business justification. Licensed apps route to an approver.
4. Do not download installers from the web or use a personal licence on a firm device — unmanaged installs are blocked and flagged by security.
5. Install started but failed: note the app name and the error, then retry once. A transient failure often clears on the second attempt.
6. Still failing, or the app is missing from the catalogue and you are unsure whether it is approved: escalate with the app name and what you need it for.
